Fiscal POS (Rep. Dominicana)

NCF Integration for Point of Sale - Dominican Republic Compliance

Overview

Fiscal POS (Rep. Dominicana) incorporates NCF (Número de Comprobante Fiscal) billing functionalities to the Point of Sale system for Dominican Republic compliance. This module enables fiscal receipt generation directly from the POS interface, ensuring full compliance with DGII regulations for retail operations.

Key Features

Fiscal Receipt Generation

Automatic generation of fiscal receipts with proper NCF numbering directly from the POS interface. The module automatically assigns the correct NCF type based on customer classification (final consumer vs. business customer) and transaction type.

Real-time validation ensures all receipts comply with DGII requirements and include all mandatory fiscal information such as NCF number, customer data, and tax details.

Customer Classification

Enhanced customer selection interface allows quick identification of customer type (final consumer or business). For business customers, the system automatically validates RNC and applies the appropriate NCF type (01 - Fiscal Credit). For final consumers, the system uses NCF type 02 (Consumer Invoice).

Smart search functionality helps quickly find registered customers and automatically applies their fiscal classification, ensuring proper tax treatment and NCF assignment.

NCF Display & Validation

Clear display of assigned NCF numbers in the POS interface provides immediate visibility of fiscal compliance status. Visual indicators show the fiscal status of each transaction and alert users to any compliance issues.

Real-time validation checks NCF sequence availability, format correctness, and DGII compliance before completing transactions, preventing fiscal errors at the point of sale.

Fiscal Payment Methods

Configure payment methods with fiscal classifications to ensure proper reporting. The module supports cash, card, and other payment types with appropriate fiscal treatment. Multi-currency support handles USD and DOP transactions with automatic exchange rate application.

Payment validation ensures all transactions meet fiscal requirements and include necessary information for DGII reporting.

Session Management

Enhanced POS session management includes fiscal validation and NCF sequence tracking. Session opening validates that all required NCF sequences are available and properly configured. Session closing includes fiscal transaction summary and validation.

Comprehensive session reports include fiscal information and NCF usage statistics, helping track compliance and sequence consumption.

Returns & Refunds

Handle returns and refunds with proper fiscal treatment. The module generates appropriate credit notes with correct NCF numbers and maintains fiscal compliance for return transactions. Automatic linking between original sales and returns ensures proper audit trail.

Validation prevents returns of non-fiscal transactions and ensures all refund transactions include proper fiscal documentation.

Accounting Integration

Seamless integration with the accounting module ensures all POS transactions are properly recorded with fiscal information. Automatic journal entries include NCF numbers, customer classification, and tax details for complete fiscal tracking.

POS transactions are automatically included in DGII reports, providing complete visibility of all business operations for fiscal compliance.

Configuration

Configure fiscal POS settings through Point of Sale > Configuration > Point of Sale. Enable fiscal mode, configure NCF sequences, and set up customer classifications to ensure proper fiscal operations.

The module includes setup wizards and comprehensive documentation to guide you through the configuration process and ensure compliance with DGII requirements.
