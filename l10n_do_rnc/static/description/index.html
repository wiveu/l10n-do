Search RNC Name

Automatic Company Information Lookup by RNC - Dominican Republic

Overview

Search RNC Name searches for company names by entering a Taxpayer Registration Number (RNC), validating company information through official Dominican Republic services. This module integrates with DGII services to automatically populate partner information, ensuring accurate and up-to-date business data.

Key Features

One-Click RNC Lookup

Simply enter an RNC number and click the search button to automatically retrieve company information from official DGII databases. The module validates the RNC format, checks for existence, and populates the partner form with accurate business information.

Real-time lookup eliminates manual data entry errors and ensures you have the most current business information for your customers and suppliers.

Automatic Data Population

When a valid RNC is found, the module automatically populates partner information including company name, business status, and available contact details. This eliminates the need for manual data entry and reduces the risk of typos or outdated information.

The system respects existing data and provides options to review and confirm changes before applying them to the partner record.

How It Works

There are two ways to look up the name with the contact's RNC / Cedula:

  • Automatic Search: Enter the RNC or Cedula in the contact's name field, the system will automatically search for the name in the available DGII database. If it cannot find it, the system will send you an error message indicating that it does not exist or is misspelled.
  • Manual Creation with Validation: Enter the company's name and RNC / Cedula when creating the contact, the system will look up the contact's RNC/Cedula name and will place the correct name. If it cannot find it, it will simply create the contact in a forced manner.

If a contact with a valid tax identification number (RNC) or ID already exists, the system will issue a warning to the user, indicating that they cannot create the contact, as this module restricts the creation of contacts with existing RNCs.

RNC Validation

Comprehensive RNC validation includes format checking, checksum verification, and status validation with DGII services. The module supports both 9-digit and 11-digit RNC formats and validates against official DGII databases.

Visual indicators show the validation status and provide clear feedback about RNC validity, helping ensure data quality and compliance.

Configuration

Configure RNC lookup services through Settings > General Settings > RNC Service. Select your preferred service provider, configure API credentials if required, and test the connection to ensure proper functionality.

The module includes comprehensive documentation and setup assistance to help you configure the optimal settings for your organization's needs.
